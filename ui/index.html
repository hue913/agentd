  1. 1

    在本机打开一条隧道

    服务器不对公网开放任何端口，所有访问都走这一条 SSH 隧道。在你 Mac 的「终端」里运行：

    ssh -N -L 8765:127.0.0.1:8765 -L 8766:127.0.0.1:8765 -L 6080:127.0.0.1:6080 root@YOUR_SERVER

    隧道开着就行，这个窗口不用管。

  2. 2

    填入访问令牌

    令牌在服务器上，读这一行就能拿到（下面的按钮会帮你复制命令）：

    ssh root@YOUR_SERVER 'cat /var/lib/agentd/api.token'

    令牌只存在这个标签页里，关闭页面就忘了。

    当 Agent 准备执行危险命令时会在这里等你。隧道断开时请求会被放弃，绝不会自动批准。

    圆桌会不绑定任何厂商：任意 OpenAI 兼容端点（含你自己的中转）或原生 Anthropic / Gemini。没配密钥的席位会如实标出，圆桌会自动跳过它。

    添加 / 更新席位

    同名席位会被覆盖；改完立即生效，不用重启

    补密钥的两条路：① 在服务器 /etc/systemd/system/agentd.env 里设置 AGENTD_* 变量并重启 agentd； ② 直接填 API Key（写入 /var/lib/agentd/agentd.json，权限 0600）。保存后点席位上的「探活」验证连通与解码档位。
